# aldh34-aldh11-evolution

This repository contains sequence alignments and phylogenetic trees supporting the manuscript:

*“ALDH34: a novel family of non-phosphorylating glyceraldehyde-3-phosphate dehydrogenases lacking the canonical catalytic glutamate”*

Zenodo DOI: 10.5281/zenodo.23068034

## Files

- aldh_families_MAFFT_ginsi_trimal_gappy_5.fasta: multiple-sequence alignment for dataset 1 (307 sequences).
- aldh_tree.nwk: maximum-likelihood phylogenetic tree inferred from dataset 1.
- aldh_cd07082_aldh7_mafftginsi_gappy_sinoutgroup.fasta: alignment of 2,578 cd07082 GAPN homologs used for the ALDH11/ALDH34 analyses; outgroup sequences are not included.
- ald34_aldh11_tree.nwk: maximum-likelihood tree inferred from 2,578 GAPN homologs and 17 ALDH7 outgroup sequences. For visual clarity, 16 ALDH7 sequences were subsequently removed, leaving one ALDH7 sequence as the outgroup in the deposited tree.

No analysis scripts are included in this release.
